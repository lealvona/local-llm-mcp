What this manages

The PII layer of local-llm-mcp: private terms the scrub always replaces (names, addresses, numbers no pattern can infer), every conversation's placeholder vault and memory, and a scrub tester that shows what each mode would remove. Values are masked at rest on this page; tick reveal values or hover a value to read it. Nothing here leaves this host.

An estimate, from what each turn gathered and returned. Input: command output and files the server read on the caller's behalf, minus the digest the caller actually received. Output: answers the worker wrote that the caller would otherwise have generated (delegations only). Carried: every token that enters a caller's context is re-sent on each later model call until compaction — assumed × context reuse calls, priced at the cache-read rate. Dollars are list prices; on a subscription they are the usage kept out of the plan's limits.
